Vice Cover Lab: an offline web app that turns your own photos and a caption into GTA 6-style cover art — multi-panel posters with bold lettering and a Vice City sunset or neon grade — exported as a PNG in square, story, and wide sizes. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, add photos, pick a layout and grade, and export.
